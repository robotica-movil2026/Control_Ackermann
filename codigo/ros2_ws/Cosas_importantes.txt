V3 Mapeo y Navegacion:

1) MAPEO CON TECLADO
Terminal 1 — Robot + controladores
ros2 launch mi_ackermann_bringup carlikebot.launch.xml
Terminal 2 — TF del láser (ajusta si tu montaje es diferente)
ros2 run tf2_ros static_transform_publisher 0.025 0.06 0.17 0 0 0 base_link laser
Terminal 3 — LIDAR
ros2 launch sllidar_ros2 sllidar_c1_launch.py
Terminal 4 — Odometría por láser
ros2 launch rf2o_laser_odometry rf2o_laser_odometry.launch.py
Terminal 5 — SLAM en modo mapping
ros2 launch slam_toolbox online_async_launch.py \
  params_file:=./src/mi_ackermann_bringup/config/mapper_params_online_async.yaml \
  use_sim_time:=false
Terminal 6 — Teleoperación por teclado
ros2 run teleop_twist_keyboard teleop_twist_keyboard \
  --ros-args -p stamped:=true \
  --remap cmd_vel:=/bicycle_steering_controller/reference
Terminal 7 — RViz para ver el mapa
rviz2
Para guardar el mapa desde el plugin de slam_toolbox en RViz: botón derecho en el panel "Slam Toolbox" → Serialize Map → pones nombre (ej. mapa_nuevo) y se guarda en maps/mapa_nuevo.data y maps/mapa_nuevo.posegraph.


2) NAVEGACIÓN AUTÓNOMA (con el mapa guardado)
Crear archivo mapper_params_localization.yaml
Necesitas una copia de mapper_params_online_async.yaml con dos cambios:
- mode: mapping → mode: localization
- Descomentar map_file_name apuntando al mapa serializado
Terminal 1 — Robot + controladores (igual)
ros2 launch mi_ackermann_bringup carlikebot.launch.xml
Terminal 2 — TF láser (igual)
ros2 run tf2_ros static_transform_publisher 0.025 0.06 0.17 0 0 0 base_link laser
Terminal 3 — LIDAR (igual)
ros2 launch sllidar_ros2 sllidar_c1_launch.py
Terminal 4 — Odometría láser (igual)
ros2 launch rf2o_laser_odometry rf2o_laser_odometry.launch.py
Terminal 5 — slam_toolbox en modo localización con el mapa
ros2 launch slam_toolbox online_async_launch.py \
  params_file:=./src/mi_ackermann_bringup/config/mapper_params_localization.yaml \
  use_sim_time:=false
Terminal 6 — Nav2 stack
ros2 launch nav2_bringup bringup_launch.py \
  params_file:=./src/mi_ackermann_bringup/config/nav2_params.yaml \
  slam:=False \
  use_localization:=False \
  autostart:=True \
  use_composition:=False
Terminal 7 — RViz
